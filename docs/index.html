Why it exists

Projects often confuse closed tickets, merged code, and a live feature. Evidence Navigator makes that gap visible before a status update becomes a claim.

Project notes→Step 3.7 Flash→Structured review→Verification task

It asks the model to treat notes as claims, not commands. The model must separate what the notes support from what still requires a real check.

How to run it

The app is deliberately small: Python standard library, one environment variable, one API request. It is intended to be copied into an existing agent or workflow.

$env:STEPFUN_API_KEY = "your-key"
python server.py
# Open http://127.0.0.1:8766
The demo uses the Step Plan base URL: https://api.stepfun.ai/step_plan/v1. The standard API channel uses separate balance and will not consume a Step Plan trial.
